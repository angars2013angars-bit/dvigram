# DviGram — мессенджер с каналами, чатами, валютой и админкой

**DviGram** — красивый и лёгкий мессенджер на **Vite + ванильный JavaScript + Netlify Functions + Netlify Blobs**. Можно запустить локально за минуту и бесплатно выложить на Netlify с рабочим сервером, регистрацией и общим чатом для всех пользователей.

---

## Что умеет

- 💬 **Личные чаты, группы и каналы**. Каждый пользователь автоматически состоит в канале **«Общий - DviGram»**.
- 🔐 **Регистрация и вход** по логину/паролю. Пароли хешируются на сервере через `scrypt`, сессия хранится в HttpOnly-cookie.
- 👑 **Встроенные аккаунты** `admin` и `dvinsky` с паролем `82Idomih)`.
- 🛡️ **Админка**: роли (пользователь / модератор / администратор), Premium, префиксы, значки, верификация, баланс, муты, баны, предупреждения.
- ✅ **Верификация**: значок галочки, при нажатии — «Пользователь верифицирован DviGram».
- 💎 **Premium подписка и права модератора** покупаются за внутреннюю валюту **DVC**. Уведомление о покупке автоматически приходит в личные сообщения аккаунту `dvinsky`.
- 🎁 **NFT-подарки**: 4 вида подарков, сохраняются в профиле получателя и отображаются карточкой в чате.
- 🎨 **Кастомизация интерфейса**: акцентный цвет, цвет имени, размер текста, стиль пузырей сообщений, узор фона. Премиум-пользователи получают оформление сообщений.
- 🌑 **3D-дизайн**: чёрный фон, анимированные сферы, кольца, кубы и алмазы, стеклянные панели на телефоне и ПК. Учитывается `prefers-reduced-motion`.
- 🖼️ **Фото в профиле**: загрузка аватарки с автоматическим уменьшением до 256×256, предпросмотр и удаление.
- 🎧 **Музыка в профиле**: загрузка MP3/M4A/WAV/OGG/WebM до 2.5 МБ, мини-плеер в чате и в профиле собеседника.
- ✨ **Статусы и ежедневный бонус**: короткий статус под именем, «серия дней» и +25 DVC раз в сутки, анимации реакций с частицами.
- ⚡ **Обмен сообщениями**: polling каждые 2,5 секунды, ответы, реакции, редактирование, удаление, файлы-заглушки, поиск, непрочитанные, двойные галочки.
- 📱 **Оптимизация для телефона и ПК**: отдельные экраны списка чатов и переписки на мобильных, safe-area для iPhone, адаптивные модалки и панели.
- 📲 **PWA**: service worker, иконки 192/512, офлайн-оболочка и встроенный тутор «Добавить на экран Домой» для Android и iOS.
- 🧪 **Демо-режим** в `localStorage`, если Netlify Functions недоступны.

## Быстрый запуск

### 1. Демо без сервера

```bash
npm install
npm run dev
```

Откройте <http://localhost:5173>. Войдите как `demo` / `demo1234`.

В этом режиме данные хранятся в браузере (`localStorage`), сервер Netlify не нужен.

### 2. Полный режим с сервером

Рекомендуется **Node.js 22** (в проекте есть `.nvmrc`):

```bash
nvm use
npm install
npx netlify dev
```

Откройте <http://localhost:8888>.

Теперь работают настоящие аккаунты, HttpOnly-cookie, Netlify Functions и Netlify Blobs. Если CLI не может подключиться к Blobs без привязки сайта, данные временно хранятся в памяти процесса — это нормально для локального режима. Для постоянного хранения выполните `npx netlify link` и выберите задеплоенный сайт.

> Если `netlify dev` падает с `Cannot read properties of undefined (reading 'prototype')` — у вас слишком новая версия Node (например, 26). Переключитесь на 22.

## Как общаться между аккаунтами

1. Откройте сайт и зарегистрируйте первого пользователя.
2. Откройте приватное окно/другой браузер и зарегистрируйте второго.
3. У обоих в списке чатов будет **«Общий - DviGram»** — просто пишите туда, сообщения появятся у всех в течение 2,5 секунд.
4. Для личной переписки: **Новый чат → Личный чат → выберите пользователя**.
5. Для канала: **Новый чат → Канал → укажите название**. Канал доступен всем пользователям.

## Админка

Войти под `admin` и открыть **Панель администратора** через кнопку 🛡️ в сайдбаре или раздел «Админка» в профиле.

Доступно:

- смена роли: пользователь / модератор / администратор;
- выдача и снятие Premium с сроком в днях;
- префикс перед именем;
- значки-эмодзи;
- верификация с галочкой;
- изменение баланса DVC;
- мут на N минут (0 — снять);
- бан на N минут (0 — снять);
- предупреждения.

Модераторы, купленные за DVC, **не имеют доступа к админке** — панель доступна только ролям `admin` и `owner`.

## Как сделать DviGram приложением на телефоне

В веб-приложении нажмите иконку **⬇︎** в шапке списка чатов (или пункт «Установить приложение» в меню профиля). На мобильных устройствах тутор также появляется сам при первом запуске.

### Android (Chrome)

1. Откройте сайт DviGram в **Chrome**.
2. Нажмите меню **⋮** в правом верхнем углу.
3. Выберите **«Установить приложение»** или **«Добавить на главный экран»**.
4. Подтвердите установку — иконка появится на экране Домой.

### iPhone / iPad (Safari)

1. Откройте сайт DviGram в **Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран «Домой»»**.
4. Нажмите **«Добавить»**.

После установки DviGram открывается в полноэкранном режиме `standalone`: без адресной строки, с собственной иконкой и интерфейсом, похожим на обычный мессенджер. Офлайн-оболочку обеспечивает `public/sw.js`.

# Тутор: бесплатный деплой на Netlify с сервером

Netlify бесплатно даёт статический хостинг, Serverless Functions и Netlify Blobs — этого достаточно для рабочей переписки.

### Шаг 1. Создайте репозиторий

В папке проекта:

```bash
git init
git add .
git commit -m "DviGram messenger"
git branch -M main
```

Создайте репозиторий на GitHub и запушьте:

```bash
git remote add origin https://github.com/<ваш-логин>/dvigram.git
git push -u origin main
```

### Шаг 2. Импортируйте в Netlify

1. Зайдите на <https://app.netlify.com>.
2. **Add new site → Import an existing project**.
3. Выберите **GitHub** и ваш репозиторий `dvigram`.

### Шаг 3. Настройки сборки

Они уже прописаны в `netlify.toml`:

| Поле | Значение |
| --- | --- |
| Base directory | пусто |
| Build command | `npm run build` |
| Publish directory | `dist` |
| Functions directory | `netlify/functions` |
| Node version | `22` |

В **Environment variables** можно добавить:

```text
SEED_ADMIN_PASSWORD = ваш_надёжный_пароль
NODE_VERSION = 22
```

`SEED_ADMIN_PASSWORD` важен только при **первом** деплое: он используется при создании аккаунтов `admin` и `dvinsky`.

### Шаг 4. Deploy

Нажмите **Deploy site**. Netlify:

1. установит зависимости;
2. соберёт Vite-бандл в `dist/`;
3. задеплоит функцию `api.mjs`;
4. включит SPA-редирект и security-заголовки.

### Шаг 5. Проверьте

Откройте выданный адрес вида `https://dvigram-abc123.netlify.app`:

1. Зарегистрируйтесь.
2. В приватном окне зарегистрируйте второго пользователя.
3. Напишите в **«Общий - DviGram»** — сообщение появится у второго пользователя за ≤2,5 сек.
4. Войдите как `admin` / `82Idomih)` и откройте админку.
5. Купите Premium за 700 DVC и проверьте сообщение у `dvinsky`.

### Шаг 6. Обновления

Достаточно коммита и `git push` в `main` — Netlify автоматически пересоберёт сайт.

### Шаг 7. Свой домен

**Site settings → Domain management → Add custom domain**. SSL-сертификат Netlify выпустит бесплатно.

## Хранение данных

Netlify Blobs (`dvigram-data`) использует ключи:

```text
users/<id>              пользователь
logins/<login>          индекс логина
sessions/<hash>         сессия
chats/<id>              чат
messages/<id>           сообщения чата
media/<userId>/music    музыка профиля (data URL)
indexes/users           список пользователей
indexes/chats           список чатов
indexes/general         общий канал
ratelimit/<key>         защита от перебора
```

## Оптимизация

- Vite минимизирует код: около **34 КБ gzip JS** и **10 КБ gzip CSS**.
- Иконки — встроенные SVG, PNG для PWA, без внешних шрифтов.
- Service Worker кэширует оболочку и статику, но не кэширует API.
- Polling останавливается в скрытых вкладках.
- Старые сообщения подгружаются по 50 штук.
- Списки используют `content-visibility: auto`.
- 3D-сцена на телефоне упрощена и полностью отключается при `prefers-reduced-motion`.
- Аватарки уменьшаются до 256×256 на клиенте до отправки на сервер.
- Адаптив работает на телефонах и ПК; на мобильных чат и список — отдельные экраны.

## Ограничения

Это учебный/демонстрационный проект, но полностью рабочий:

- нет end-to-end шифрования;
- WebSocket заменён polling (2,5 сек);
- файлы в чате прикрепляются как карточки, байты не загружаются;
- аватарка ограничена 320 КБ, музыка — 2.5 МБ из-за лимита Netlify Functions;
- музыка профиля воспроизводится только после пользовательского нажатия (ограничение автоплея браузеров);
- нет восстановления пароля и подтверждения email;
- это не блокчейн-NFT — подарки хранятся в Blobs;
- обязательно смените `SEED_ADMIN_PASSWORD` перед публикацией.

Для продакшена лучше подключить Postgres/Supabase и WebSocket/Realtime.

## Частые проблемы

**Вижу «Демо-режим».** Вы запустили `npm run dev` без Netlify CLI. Используйте `npx netlify dev` для серверного API.

**Данные исчезают после перезапуска `netlify dev`.** Сайт не привязан к Netlify. Выполните `npx netlify link`.

**Не удаётся войти как admin.** Проверьте пароль. Если вы задали `SEED_ADMIN_PASSWORD` до первого деплоя, используйте его вместо `82Idomih)`.

**Сообщения не обновляются.** Polling приостановлен в скрытой вкладке — вернитесь на неё.

**`netlify dev` падает.** Переключитесь на Node 22 (`nvm use`).
